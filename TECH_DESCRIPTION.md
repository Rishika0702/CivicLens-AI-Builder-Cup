# Technology description

CivicLens turns multilingual citizen reports into prioritized municipal actions. Its responsive frontend uses HTML/CSS/JavaScript with Leaflet with Esri map tiles for an incident map and browser speech recognition for speech-to-text where supported. A Python FastAPI backend receives text, location, and optional photo bytes. Gemini 2.5 Flash, configured server-side with a rotated secret, assigns category, urgency, and a concise summary; without Gemini, the application explicitly uses a deterministic fallback. Incoming reports are linked to incidents of the same category within 700m, demonstrating consolidation of 50 synthetic reports into 5 incidents. The municipal queue ranks incidents by urgency and report volume. Firebase Admin SDK supports ID-token verification and optional Firestore writes. A Dockerfile and Cloud Run deployment script enable Google Cloud hosting. This is a demo-stage prototype; stronger identity, durability, clustering, privacy, and moderation are future work.
